Hubungkan konteks. Kendalikan izin.

Jembatan manual antara ChatGPT Go dan CerdikGo. Ekspor atau bagikan tugas sebagai JSON, impor dengan validasi, lalu buat rencana non-eksekusi di CerdikGo.

Jangan masukkan password, API key, token, data pelanggan, atau informasi rahasia. Transfer hanya terjadi saat Anda menekan tombol. Inbox disimpan sementara di sesi browser ini.

1 · Buat paket tugas

Tempel instruksi dari ChatGPT Go atau tulis permintaan baru. Paket ini tidak menjalankan agent.

2 · Impor paket ChatGPT

Pilih file JSON yang diekspor atau tempel JSON. Sistem memeriksa skema, ukuran instruksi, ID, dan daftar agent.

3 · Task Inbox & Governance Gate

Inbox sementara pada tab/sesi browser. Pilih tugas tervalidasi untuk membuat ringkasan rencana lokal. Fitur ini tidak mengirim data ke server dan tidak mengeksekusi agent.

P0 safeguard: pertukaran JSON dan Inbox berlangsung lokal pada tab ini. Tidak ada eksekusi agent, database write, panggilan provider eksternal, atau akses Production. Rencana controlled action tetap menunggu persetujuan manusia.
