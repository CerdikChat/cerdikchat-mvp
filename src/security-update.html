Keamanan file sedang kami tingkatkan.

CerdikGo dan CerdikChat sedang menyiapkan Antivirus Security Gateway. Sampai scanner privat tersedia dan lolos pengujian, unggahan PDF/gambar tetap dikunci. Beta tetap dapat berjalan melalui AI Chat berbasis teks.

● Pengembangan & validasi Preview berlangsung
🛡️

Antivirus Security Gateway

Lapisan pemeriksaan file telah dikembangkan dengan kontrak integrasi ClamAV. Scanner engine masih dalam tahap penyediaan dan belum dinyatakan aktif.

🔒

Fail-closed protection

Jika scanner tidak tersedia, timeout, atau memberikan hasil yang tidak dapat diverifikasi, file ditolak dan tidak diteruskan ke AI.

🧪

Automated tests passed

Regression CI untuk adapter scanner dan perilaku fail-closed telah lulus. Ini adalah hasil pengujian kode, bukan bukti bahwa engine antivirus sudah berjalan.

📱

Preview validation next

Berikutnya: integrasi scanner privat, pengujian file bersih dan EICAR, lalu verifikasi alur upload melalui Android Chrome.

Roadmap verifikasi

Empat langkah sebelum perlindungan dinyatakan aktif

  1. 01Provision scanner
    Menyiapkan engine ClamAV privat dan pembaruan signature database.
  2. 02Isolated Preview binding
    Menghubungkan scanner hanya ke lingkungan Preview, terpisah dari Production.
  3. 03Security test
    Memastikan file bersih dapat diproses dan file uji EICAR ditolak sebelum AI processing.
  4. 04Android end-to-end validation
    Memeriksa upload, respons, batas ukuran, kegagalan scanner, dan pengalaman pengguna.
Transparansi status: Antivirus belum aktif pada layanan pengguna. Unggahan file tetap dikunci dan permintaan API tetap fail-closed sampai engine ClamAV privat terpasang serta seluruh pengujian runtime lulus. Alternatif beta: tempel teks non-sensitif langsung ke AI Chat (maksimum 8.000 karakter). Teks yang dikirim diproses oleh AI; jangan masukkan kata sandi, data pribadi sensitif, atau dokumen rahasia. Kami tidak akan mengklaim file telah dipindai jika pemeriksaan belum benar-benar dilakukan.
